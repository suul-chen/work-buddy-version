# 校招项目全周期工作台 · Work Buddy

> 一个属于自己的、可随手记录的**可视化校招全周期工作台**——从调研到落地，把多个求职项目的任务、交付物、过程留痕统一管理，改简历时能直接复用。

## 项目背景

我正在准备校招，需要一套**自己的工作台**，把多个求职项目（招商局、特发集团、高新投、兴邦金租等）从启动到交付的**全周期任务**统一管理起来。

核心出发点（来自最初的手写设想）：

- 想要一个**能随时更新、可重新配置的工作台**
- 主要靠收集：**粘贴零散的任务/想法/记录**，而不是每次都手动逐条录入
- 希望有类似 **MS Project 式甘特图**（不同视角、含进度线），方便在面试时向对方展示信息量的同时体现时间感
- 录入后要在对应的时间点**自动检查信息是否完整**（起始时间、预计交付时间、实际交付时间、任务类型、内容、难点、交付成果）
- 任务要有**标签体系**（按重要程度排序），还要支持**点击文件就能下载或预览**
- 可以把不同项目的**输入/输出任意关联起来**，区分不同维度的每条任务
- 关于**表型呈现和用率的数据**，希望像 Roadmap 那样有个大的概览，所有信息都有据可查且容易展示
- 录入时**文字形式想要一个语音或者敲字的效果**（打字机效果），内容存的时候可以直接导出下载
- 可能需要考虑一个**工作日历类的录入**，因为很多任务不是"一天之内完成的"，可能一天的录入一次都不够
- 关键是**表型呈现**，希望这个功能在录入的时候就可以用，因此这一块应该跟后续的功能联动
- 任务的工作日志里要**记录我获得的信息**，完成工作后**根据分区汇总生成以任务作为区域的工作流**
- 然后可以看**概览板**，我想通过实际交付的时间来查看每个任务的**基本完成情况**，最终的任务成果通过一个**报告来输出**
- 最好可以通过**后续各条系统的条目显示**出任务条目，从而看到整体的**任务信息**
- 我还有个**碎碎念板块**，按照日期记录感悟，主要是在每天工作完之后在下面**三十左右有问则答**之后**随意自由发挥**
- 做的是**校招类**，所以数据可能需要**按某个文本的关键词进行分类**（比如"宣传"相关的一类、"执行"相关的一类）
- 如果有**层级的话更好**（比如像**做效果**），那么**再再就是应该出**天量**第二版**
- 还需要一个**每日/周报选择一个自动化模块**，通过**确认**每天填入的工作日志需要**出**，因为有这些**任务填着比较长**，一天不一定都能做完，可能就只做了一个 **version**
- 我需要把每个工作的**信息都会被录入进去**，后面有一个**查询面板**，然后主要面里面**加一个搜索框**，我要找什么都可以**查到**，**甚至可以根据一些关键词**
- 还有我**记录想法的一个工作台**，可以做一个「**碎碎念**」板块，只是**记录自己的想法**，所以**哪怕只有日期和分项和基础信息的都可以**，甚至**连查询面板都不需要**

## 核心目标

| 目标 | 说明 |
|------|------|
| **收集** | 录入每个项目的任务、交付物、过程留痕 |
| **总结** | 量化自己在每个项目里完成了什么——按时间、任务类别、整体把控呈现 |
| **显示** | 用可视化看板 + 文字总结，体现"从调研到落地的项目全周期经历"，改简历时能直接复用 |

最终目的：证明自己是一个**有条不紊、有深入项目全周期经历**的候选人；所有信息可随时复盘、可量化。

## 功能一览

### 五大模块

| 模块 | 编号 | 说明 |
|------|------|------|
| **概况** | №01 | 快录框（自然语言识别）→ 弹窗确认 → 自动写日志；本周指标卡；今日代办；最近动态；报告生成入口 |
| **Roadmap** | №02 | 项目卡片网格（可拖拽排序）→ 项目专属看板；MS Project 风格甘特图（月视图、飞书式拖拽平移）；筛选排序栏 |
| **文件库** | №03 | 文件快录（支持飞书分享链接自动识别）；文件表（点击文件名直接打开/预览/下载）；筛选（项目/类型/日期） |
| **碎碎念** | №04 | 随手记录感悟，按日期归档，不进入日报 |
| **工作日志** | №05 | 自动记录每次操作，按天分组 + 搜索 |

### 核心能力

- **自然语言识别录入**：`parseQuick()` / `parseFile()` 自动识别项目、类型、日期、内容
- **批量录入**：`parseBatch()` 粘贴一段混合多项目的随手记 → 自动拆成多条结构化任务 → 预览编辑 → 批量保存
- **关键词模糊索引**：项目别名表（特发=特发集团、高薪投=高新投）+ 类型别名表（校招启动文=简章→文案宣传类），录入即归一
- **母任务 / 子任务**：`parent` 字段预留树形结构（开发中）
- **任务 ↔ 文件关联**：`linkedFiles` 字段，任务行内可直接打开关联文件（开发中）
- **自动化报告**：日报/周报/代办一键起草 + 定时提醒（周一~周四 17:50 日报、周五 17:30 周报），量化摘要 + 可编辑转待办
- **报告内联展示**：生成后直接显示在概况页，标注精确到分
- **甘特图飞书式拖拽**：鼠标/触摸/滚轮拖拽平移时间轴
- **版本迭代留痕**：`version` / `feedback` 字段追踪任务变更历史

## 开发约束

- **基线唯一**：以 work buddy 版为唯一演进版本
- **形态不变**：单文件纯静态 HTML+CSS+原生 JS，无构建、无后端，localStorage 持久化
- **视觉不变**：poster/编辑风（暖米底 #efeae0、近黑字 #0a0a0a、强红 #e63946、编号页眉、入场动画）
- **向后兼容**：任何字段新增都经 `normalize()` 补齐，旧数据用户不丢
- **可修改性**：所有自动识别的信息都必须可手动改（识别可能错）
