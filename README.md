# 校招全周期工作台

> Work Buddy · 一款面向校招 / 实习场景的**可视化项目管理工作台**。将多个求职项目的任务、交付物与过程留痕统一管理，从调研到落地形成可复盘、可量化的全周期记录，也能在简历与面试中直接复用。

## 在线访问

**点击进入应用（v6.5）**：https://suul-chen.github.io/work-buddy-version/work-buddy-version.html

## 为什么做这个

校招是一场多线程的持久战。同一段时间里，往往要同时跟进招商局、特发集团、高新投、兴邦金租等多个项目的测评、笔试、面试与实习任务——每个项目有各自的节奏、截止线与交付物，信息散落在聊天记录、云文档和便签里，复盘时很难拼出一条完整的成长路径。

通用的办公工具要么太"轻"（聊天记录、备忘录记了就散），要么太"重"（专业项目管理软件的学习成本和协作属性，对单人使用并不友好）。这个作品想填补中间的空白：**一个完全属于自己的、随手可记录、又能结构化呈现的单人工作台**——它不追求取代团队工具，而是把"这段时间到底做了什么、做到了哪一步"讲清楚。

作品的定位是一份**个人校招 / 实习作品集**：它既是日常使用的效率工具，也是一份能直接展示给面试官看的"项目全周期履历"。

## 功能一览

Work Buddy 以左侧导航的五大模块组织全部功能，从录入、管理到展示形成闭环。

### №01 概况 · 总览与录入入口

- **快录框（自然语言识别）**：输入一段自由文本，`parseQuick()` 自动识别项目、类型、日期、内容，弹窗确认后即可写入并自动生成工作日志。
- **批量录入**：`parseBatch()` 支持粘贴一段混合多项目的随手记，自动按上下文拆成多条结构化任务，预览编辑后批量保存，适合一次性整理一天的零散记录；支持两行卡片式批量填入，录入更快。
- **关键词模糊索引**：录入时自动归一——"特发"与"特发集团"、"高薪投"与"高新投"归为同一项目，校招启动文 / 简章归为文案宣传类，检索时不再各说各话。
- **本周指标卡 + 今日代办**：一眼看清本周进展与当天待办。
- **报告生成入口**：日报 / 周报 / 代办一键起草，并带定时提醒（周一~周四 17:50 日报、周五 17:30 周报）；生成结果直接内联展示在概况页，标注精确到分。
- **数据备份（导入 / 导出）**：概况页「数据备份」卡片支持一键 **导出备份**（整份 `state` 序列化为 JSON 下载）与 **导入备份**（覆盖 / 合并两种模式），换设备、清缓存都不丢数据（4.7）。
- **指标卡详情弹窗**：概况页「本周任务总数 / 已交付 / 进行中 / 未开始」四张指标卡可点击，弹出按状态 / 项目分组的任务明细，点击任务条可跳转对应看板（v6.5）。

### №02 Roadmap · 项目看板与甘特

- **项目卡片网格**：各求职项目以卡片呈现，支持拖拽排序。
- **项目专属看板**：点进任一项目查看其任务流转。
- **MS Project 风格甘特图**：按月视图呈现任务时间轴，支持鼠标 / 触摸 / 滚轮拖拽平移（飞书式交互），带今日线。
- **筛选排序栏**：按项目、类型、状态快速定位。
- **母任务 / 子任务树形折叠**：任务支持父子层级，母任务可一键展开 / 收起子任务，长清单也井井有条；子任务创建已修复 id 冲突导致的写入失败。
- **双击任务行直接编辑**：看板表格行双击即打开编辑弹窗；任务类型可在编辑页直接更换，类型管理集中在添加 / 批量 / 筛选三处（不在单任务页内）。
- **甘特图连接起止日期**：红色任务条连接「起始日期 → 实际交付日期」，条内优先显示「天数 + 任务名」，空间不足时只显示天数；悬停看完整名称。
- **编辑体验打磨（v6.5）**：任务编辑弹窗「整体进度」加 25 / 50 / 75 / 100 快捷按钮；「反馈意见 / 难点和动作」改为自适应高度 textarea；状态术语统一为「未开始 / 进行中 / 已交付」。

### №03 文件库 · 交付物管理

- **文件快录**：`parseFile()` 支持粘贴飞书分享链接自动识别文件名；录入时填写文件名 / 项目 / 类型 / 上传日期。
- **表格直达**：文件名带链接时蓝色可点击 ↗，新标签页直接打开飞书在线预览 / 下载。
- **筛选**：按项目 / 类型 / 日期过滤交付物。

### №04 碎碎念 · 自由记录

- 随手记录工作感悟，按日期归档，作为非正式随笔，**不进入日报**，保留最真实的思考片段。

### №05 工作日志 · 操作留痕

- 自动记录每次增 / 改 / 删操作，按天分组并支持搜索；任务带 `version` / `feedback` 字段，迭代变更可回溯。

## 开发约束

- **基线唯一**：以 work buddy 版为唯一演进版本，不再分叉
- **形态不变**：单文件纯静态 HTML + CSS + 原生 JS，无构建、无后端，localStorage 持久化
- **视觉方向**：暖米底 + 强红强调的柔和工作台风（圆角卡片、胶囊按钮、轻阴影、编号页眉、入场动画）
- **向后兼容**：任何字段新增都经 `normalize()` 补齐，旧数据用户不丢
- **可修改性**：所有自动识别的信息都必须可手动改（识别可能错）
